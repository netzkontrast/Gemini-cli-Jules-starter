# Duplicate and Analyze Workflow

## Purpose
Duplicate a specific file and perform a refactoring analysis on it.

## Process

1.  **Duplicate File**
    - Takes a target file path.
    - Creates a copy (e.g., `filename_copy.ext` or `filename.bak`).

2.  **Analyze Code**
    - Runs a code quality and refactoring analysis on the *duplicated* file.
    - Suggests improvements based on best practices.

## Output
- A report of the analysis.
- The duplicated file remains for reference.

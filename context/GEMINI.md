# Project Gemini Context

## Overview
This project establishes a Python-based framework for agentic context orchestration.

## Core Principles
1. **Context-Driven:** All tasks must be grounded in the provided context files.
2. **Persistence:** Learnings are stored in `logs/` and reflected in `SKILL.md` updates.
3. **Separation of Concerns:** Project context is static; Workflow context is dynamic.
